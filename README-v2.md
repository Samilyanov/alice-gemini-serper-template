# Джарвис v2

Новая версия доступна по `/api/v2`. Старый `/api` сохранён для отката.
В Яндекс Диалогах адрес черновика переключён на новую версию.

## Как пользоваться

- Задайте обычный вопрос. Ответ составляет Google Gemini.
- Если ответ готовится, через несколько секунд скажите «Продолжай» или нажмите одноимённую кнопку. Запрос не создаётся заново.
- «Новая тема» сбрасывает контекст текущего разговора.
- «Стоп» завершает сессию.
- Для поиска скажите «Найди…», «Поищи…» или задайте вопрос со словами «сегодня», «погода», «новости» и т. п. Serper ищет информацию, Gemini составляет ответ по найденным фрагментам.
- Память действует в пределах сессии навыка. Между разными запусками память не сохраняется.

## Почему ответ не теряется

Gemini Interactions API выполняет запрос в фоновом режиме на стороне Google.
Наш webhook ждёт не более 3,2 секунды. Если генерация ещё идёт, возвращает приглашение сказать «Продолжай».
Повторная команда получает результат той же задачи. Фоновое выполнение не зависит от памяти конкретной функции Vercel.

В `session_state` хранятся только номера текущей и предыдущей задач, время создания и HMAC-подписи, связанные с сессией. История не пересылается в состоянии Алисы: лимит Яндекса составляет 1 КБ. Подписи вычисляются на сервере; ключ API в ответ не включается.

## Настройки

Секреты задаются в Vercel Environment Variables, не в GitHub:

- `GEMINI_API_KEY` — существующий ключ Google AI Studio.
- `SERPER_API_KEY` — существующий ключ Serper.
- `GEMINI_BACKGROUND_MODEL` — необязательная модель с поддержкой Interactions background. По умолчанию пробуется `gemini-3.5-flash-lite`; если проект не поддерживает на ней фоновый режим, используется `gemini-3.1-flash-lite`. При явном указании модели автоматической замены нет.

`GEMINI_MODEL` относится к старому `/api` и не влияет на v2.
После изменения переменных нужно выполнить Redeploy.

Используется `store: true`: Google сохраняет Interactions для истории разговора. По документации фонового API срок хранения составляет 7 дней. «Новая тема» удаляет ссылку из сессии, но не является удалением истории из Google. Не вводите секреты в разговор.

## Проверки

Запуск: `npm test` (Node.js 22+). Внешние ключи для тестов не нужны; API подменены тестовыми ответами.

Проверяются: протокол Алисы, границы ответа и состояния, отложенный ответ после смены процесса, продолжение без повторной генерации, контекст, подделка номера задачи, изоляция сессий, истечение срока, поиск, отсутствие результатов, сетевые ошибки, неверные ключи, квота, незавершённые ответы, реальное срабатывание таймера и параллельные сессии.

Vercel выполняет `npm test` перед развёртыванием. При падении тестов новая версия не становится рабочей.
Логи содержат маршрут обработки, длительность и коды ошибок; тексты вопросов и ключи в них не записываются кодом приложения.

## Ограничения

- Быстрый ответ Gemini не гарантирован: иногда требуется несколько команд «Продолжай». Алиса сама не может произнести ответ без следующего обращения пользователя.
- После 10 минут ожидания задача перестаёт приниматься в текущей сессии; вопрос потребуется задать заново. Ссылка на контекст принимается до 6 часов в пределах той же сессии.
- Результаты поиска — фрагменты страниц, а не проверенный полный текст статей. Даты и полноту информации нельзя гарантировать. Модель получает инструкцию не выдавать неподтверждённые сведения за сегодняшние.
- Если сам запуск фоновой задачи не успел вернуть номер, восстановить неизвестный номер невозможно: пользователь получает честную ошибку соединения. Следующая попытка может создать новую задачу.
- Серверный таймер не охватывает доставку запроса Яндексом и запуск функции Vercel. При проблемах сети возможны внешние таймауты.
- Проверка на реальной колонке требует устройства пользователя; браузерный тестер проверяет протокол, но не качество распознавания речи на колонке.

## Откат

В Яндекс Диалогах замените окончание Webhook URL `/api/v2` на `/api`, сохраните и перезапустите тестовую сессию. Старый обработчик сохранён.
